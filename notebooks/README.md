# PROJECT MIRROR — Research Notebooks

## Monnier Research Division
Cavendish Group

This directory contains computational experiments
investigating human behavioral predictability,
causal inference, personality development,
and synthetic variations.

## Research Objectives

- Predict human behavioral decisions.
- Investigate the causes of human behavior.
- Examine personality divergence over time.
- Evaluate the predictive value of synthetic variations.

## Research Methods

- Machine Learning
- Regression
- Matching
- Simulation
- Fixed Effects
- Event Studies
- Differences-in-Differences
- Causal Diagrams
- Treatment Effects
- Instrumental Variables
- Regression Discontinuity
